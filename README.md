# Ruben Salido
Language Technology • Applied AI • Natural Language Processing • Computer Vision

M.S. Computer Science candidate at Northeastern University with a professional background in language education, interpretation, and applied linguistics.

My interests sit at the intersection of computer science and human language, with a focus on how natural language processing, machine learning, and computer vision can be applied to technologies that support second-language learning and communication.

My academic experience includes software development, data structures, algorithms, machine learning, artificial intelligence, computer vision, and natural language processing. 

## Featured Projects
### [¿Lleva Tilde?](https://github.com/ElGavaOriginal/lleva-tilde)
A Spanish-language mobile application that uses linguistic rules and dictionary-based logic to determine whether a word in Spanish requires an accent mark. 

### [¿Qué es?](https://github.com/ElGavaOriginal/que-es)
A computer vision and language-learning project that uses object recognition to connect real-world objects to Spanish articles. 

### [Camera Calibration & Augmented Reality](https://github.com/ElGavaOriginal/camera-calibration-ar)
A computer vision project implementing camera calibration, pose estimation, feature detection, and augmented-reality projection using OpenCV.
